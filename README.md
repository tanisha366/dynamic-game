# ArtVerse - Professional Art Marketplace

A stunning, modern art gallery and marketplace website built with React, GSAP, and Framer Motion.

## 🎨 Features

- **Hero Section** with smooth GSAP animations and floating particles
- **Featured Artists** grid with smooth scroll triggers
- **Curated Artworks Gallery** with filtering and modal details
- **Collection Showcase** with professional card designs
- **Why Collect** section with feature highlights
- **Newsletter Subscription** with smooth interactions
- **Responsive Design** - Works perfectly on all devices
- **Smooth Animations** - GSAP and Framer Motion for stunning effects
- **Dark Professional Theme** - Modern color scheme with gradients

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

Visit `http://localhost:5173` to see the site.

## 📦 Tech Stack

- **React 18** - UI library
- **Vite** - Build tool
- **GSAP** - Animation library
- **Framer Motion** - React animation library
- **Lucide React** - Icon library

## 🔧 Customization

### Colors
Main colors are defined in CSS. Update gradient colors in component CSS files:
- Primary: `#a855f7` (Purple)
- Secondary: `#ec4899` (Pink)
- Accent: `#f97316` (Orange)

### Content
Update artwork, artist, and collection data by editing the arrays in each component.
